# Rate API

API курсов

## Запуск в Docker

Нужен Docker с Compose. PHP, Composer и Symfony CLI устанавливаются внутри образа.

```bash
docker compose build --pull
docker compose run --rm app composer install --no-interaction
docker compose up -d
docker compose exec app php bin/console app:rates:update
```

## Обновление курсов

```bash
docker compose exec app php bin/console rate:update
```


Файл `var/rates.json` создаётся автоматически; путь задаётся через `RATES_FILE`
относительно корня проекта. В нём сохраняются `base`, `updated_at` в UTC и словарь
`rates`. 

## Получение курсов

```bash
curl 'http://127.0.0.1:8081/api/rates'
curl 'http://127.0.0.1:8081/api/rates?base=EUR'
curl 'http://127.0.0.1:8081/api/rates?base=BTC'
```

`base` — любая валюта из файла. Значение по умолчанию задаётся переменной
`DEFAULT_BASE_CURRENCY` в `.env` (изначально `USD`); его можно переопределить
в `.env.local`. Параметр запроса имеет приоритет. Регистр не важен, пробелы по краям
удаляются. `RatesRequest` принимает query string через `MapQueryString` и проверяет
`base` через Symfony Validator: непустой код из 1–16 латинских букв или цифр,
затем наличие валюты в сохранённом файле через `SupportedCurrency`.
Его валидатор получает `RateStorage` через DI. Проверки объединены в `Sequentially`,
поэтому при ошибке формата файл не читается. Недоступный или повреждённый файл
возвращает `503`.
При отсутствии параметра используется настройка из окружения; пустой, неверно
сформированный или неизвестный код возвращает JSON-ошибку `400`.
Пример для условного курса `USD → EUR = 0.8`:

```json
{
  "base": "EUR",
  "rates": [
    {"rate": "1", "code": "EUR"},
    {"rate": "1.25", "code": "USD"}
  ]
}
```

Формула: `rate(code, base) = usd_rate(code) / usd_rate(base)`.

## Конвертация

```bash
curl 'http://127.0.0.1:8081/api/convert?amount=1&from=BTC&to=USD'
curl 'http://127.0.0.1:8081/api/convert?amount=125.50&from=EUR&to=BTC'
```

Обязательные параметры: `amount`, `from`, `to`. Поддерживаются ноль,
дробные и большие неотрицательные суммы, а также научная запись (`1e-8`).
Лимит входного числа — 256 символов, экспоненты — от -128 до 128.
Для `+` в query string используйте URL-кодирование `%2B`.

Параметры принимает `ConvertRequest` через `MapQueryString`: сумма проверяется
с помощью `Decimal`, обе валюты — через `SupportedCurrency`. Сначала проверяются
сумма и формат кодов, затем наличие валют в файле. Ошибки параметров возвращают `400`,
недоступный или повреждённый файл — `503`.

Пример для условной цены BTC = 50000 USD:

```json
{
  "amount": "50000",
  "currency_from": {"rate": "0.00002", "code": "BTC"},
  "currency_to": {"rate": "1", "code": "USD"}
}
```

`amount` в ответе — сумма в `to`. В этом ответе базой для полей `rate` служит
валюта назначения: `currency_to.rate` всегда `1`, а `currency_from.rate` —
количество исходной валюты за одну единицу целевой.

Формула: `result = amount × usd_rate(to) / usd_rate(from)`.

Все суммы и курсы в JSON — **строки**, чтобы клиенты не теряли точность.
Числовые токены внешнего JSON тоже читаются как строки до преобразования в PHP;
`float` в расчётах не используется. Курсы делятся с точностью 32 знака после точки.
Сумма округляется один раз до 8 знаков, половина округляется вверх; конечные нули
удаляются. Поэтому результат менее `0.000000005` будет `"0"`.

Ошибки возвращаются в JSON: `{"error":"..."}`.

- `400`: отсутствующий/неверный параметр, отрицательная сумма, неизвестная валюта.
- `503`: файл курсов отсутствует, недоступен или повреждён.
- `405`: HTTP-метод отличается от GET.

## Новый источник

Создайте класс в `src/Service/RateProvider`, реализующий `RateProviderInterface`.
Метод `fetch(): array` должен вернуть словарь `CODE => decimal-string`:
количество валюты за 1 USD, положительные значения. При ошибке выбрасывайте исключение.
Провайдер автоматически получит тег `app.rate_provider` и попадёт в `RateUpdater`.
Команду и эндпоинты менять не требуется. Если нужно управлять приоритетом при
совпадении кодов, добавьте атрибут `#[AsTaggedItem(priority: 50)]` из пространства
имён `Symfony\Component\DependencyInjection\Attribute`. У FloatRates приоритет 100,
у остальных по умолчанию 0; первым используется больший приоритет.

## Проверки

```bash
docker compose exec app composer check
```

Команда запускает PHPUnit, PHPStan (уровень 8), проверку DI-контейнера и YAML.
Тесты провайдеров используют MockHttpClient, тесты HTTP — отдельный файл
`var/test/rates.json`. Сеть и реальные курсы для тестов не нужны.
