# Rate API

API предоставляет сохранённые курсы валют и конвертирует суммы между ними.


## Формат данных

Успешный ответ содержит `success: true` и объект `data`.
Обработанная ошибка содержит `success: false` и строку `error`;
ошибка валидации дополнительно содержит `errors` с сообщениями по полям.

Все суммы и курсы передаются **строками**, чтобы сохранить точность.
Коды валют содержат от 1 до 16 латинских букв или цифр. 
Регистр не важен, пробелы по краям кодов удаляются. 
Валюта должна присутствовать в сохранённых курсах.

## Получение курсов

`GET /api/rates`

| Параметр | Обязательный | Описание |
| --- | --- | --- |
| `base` | Нет | Базовая валюта, например `USD`, `EUR` или `BTC`. Если параметр отсутствует, используется `DEFAULT_BASE_CURRENCY` (по умолчанию `USD`). Пустое значение недопустимо. |

```bash
curl 'http://127.0.0.1:8081/api/rates?base=EUR'
```

Ответ **200 OK**:

```json
[
  {
     "rate": "1",
    "code": "EUR"
  },
  {
    "rate": "1.25",
    "code": "USD"
  }
]
```

`rates` — массив объектов с полями `code` и `rate`. Каждый курс показывает,
сколько единиц указанной валюты приходится на одну единицу `base`.
В примере `1 EUR = 1.25 USD`. Курс самой базовой валюты равен `"1"`.

Запрос без параметров:

```bash
curl 'http://127.0.0.1:8081/api/rates'
```

## Конвертация суммы

`GET /api/convert`

| Параметр | Обязательный | Описание |
| --- | --- | --- |
| `amount` | Да | Неотрицательная сумма в исходной валюте. Десятичный разделитель — точка. |
| `from` | Да | Код исходной валюты. |
| `to` | Да | Код целевой валюты. |

```bash
curl 'http://127.0.0.1:8081/api/convert?amount=10&from=EUR&to=USD'
```

Ответ **200 OK** при условном курсе `1 EUR = 1.25 USD`:

```json
{
    "amount": "12.5",
    "currency_from": {
      "rate": "0.8",
      "code": "EUR"
    },
    "currency_to": {
      "rate": "1",
      "code": "USD"
    }
}
```

| Поле ответа | Значение |
| --- | --- |
| `amount` | Результат конвертации в валюте `to`. |
| `currency_from.code` | Код исходной валюты. |
| `currency_from.rate` | Количество исходной валюты за одну единицу целевой: в примере `1 USD = 0.8 EUR`. |
| `currency_to.code` | Код целевой валюты. |
| `currency_to.rate` | Всегда `"1"`. |


## Ошибки

### 400 — ошибка валидации

Возвращается при отсутствующих обязательных параметрах, неверном формате,
отрицательной сумме или неизвестной валюте.

```bash
curl 'http://127.0.0.1:8081/api/rates?base=XXX'
```

```json
{
  "success": false,
  "error": "Validation failed.",
  "errors": {
    "base": ["Unknown currency: XXX."]
  }
}
```

`errors` может содержать несколько полей; значение каждого — массив сообщений.
Для конвертации используются поля `amount`, `from` и `to`.
Сначала проверяется формат параметров, затем наличие валют, поэтому один ответ
не обязательно содержит все возможные ошибки запроса.

Ошибка аргумента, обнаруженная непосредственно сервисом, возвращается без `errors`:

```json
{
  "success": false,
  "error": "Unknown currency: XYZ."
}
```

### 503 — курсы недоступны

Возвращается, если файл курсов отсутствует, недоступен для чтения или повреждён,
в том числе при проверке валют до вызова контроллера.

```json
{
  "success": false,
  "error": "Rates are currently unavailable."
}
```

### 500 — внутренняя ошибка сервиса

Неожиданная ошибка, перехваченная контроллером при вызове сервиса:

```json
{
  "success": false,
  "error": "Internal server error."
}
```

В этих обработанных ответах отсутствуют трассировка, пути к файлам и классы
исключений. Подробности серверных ошибок записываются в лог.

Ошибки маршрутизации, например неизвестный адрес (`404`) или неподдерживаемый
метод (`405`), обрабатывает Symfony; описанный выше формат для них не гарантируется.

## Обновление данных

HTTP-запросы читают сохранённые курсы. Для первоначального получения данных
и последующих обновлений выполните команду:

```bash
docker compose exec app php bin/console rate:update
```

Базовую валюту обновления можно передать аргументом:

```bash
docker compose exec app php bin/console rate:update EUR
```

Она должна входить в `ALLOWED_BASE_CURRENCIES`. Без аргумента используется `DEFAULT_BASE_CURRENCY`.
Путь к файлу задаётся через `RATES_FILE` относительно корня проекта.

Параметр HTTP-запроса `base` может указывать любую валюту из сохранённого набора,
независимо от базовой валюты последнего обновления.
